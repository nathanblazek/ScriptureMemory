# Scripture Memory

A Windows app for memorizing scripture. Built with WinUI 3 (Windows App SDK) and .NET 8.

![icon](Assets/app-preview.png)

## Features

- **Collections**: group the passages you're memorizing, and add any verse range by picking book/chapter/verses or typing a reference (`Romans 8:28-39`, `John 3:16-4:2`).
- **ESV text**: passages come from the [ESV API](https://api.esv.org/).
- **Practice views**:
  - **Show all**: the full text.
  - **First letters**: each word becomes its first letter plus blanks (`Jesus` → `J____`).
  - **Blur**: every word is blurred.
  - Click any hidden word to reveal it; **Reset** hides everything again.
- **Speak**: recite out loud and words are revealed as you say them. This uses the offline Windows speech recognizer, steered toward the words you're expected to say next, and it forgives dropped small words, near-misses, and restarts.
- **Calibrate voice**: read a passage aloud with the text showing. This trains the Windows voice profile and gives extra leeway to words the recognizer finds hard to hear in your voice.
- **Progress**: completion counts and a "mastered" flag per passage.

## Setup

1. Get a free ESV API key at <https://api.esv.org/account/create-application/>.
2. Run the app, click **ESV API key**, and paste it in. It's stored encrypted for your Windows account.

App data lives in `%LOCALAPPDATA%\ScriptureMemory\data.json`.

## Build

Requires the .NET 8 SDK.

```
dotnet build
dotnet run
```

Single-file executable:

```
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:IncludeAllContentForSelfExtract=true -o publish\release
```

The icon is generated by `Assets/make-icon.ps1`.
